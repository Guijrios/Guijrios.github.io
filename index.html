Projetos em Destaque

🌿 Classificação Few-Shot de Doenças em Plantas via Fusão de Características Global-Local

Python PyTorch Jupyter Visão Computacional

Este projeto implementa uma abordagem de Few-Shot Learning (FSL) para classificação de doenças em folhas de plantas, baseada na fusão de características globais e locais com mecanismo de autoatenção. A proposta é investigar como um modelo pode realizar a classificação de diferentes doenças utilizando apenas uma pequena quantidade de imagens de referência, reduzindo a necessidade de grandes conjuntos de dados específicos para cada nova classe.

🧩 Resolução do Nonograma usando Algoritmos de IA

IA Backtracking Algoritmo Genético Modelo Híbrido

Este projeto apresenta a implementação de um solucionador de Nonogramas, um jogo de lógica em que o objetivo é preencher uma malha de acordo com sequências numéricas fornecidas para cada linha e coluna. Essas sequências indicam a quantidade e a ordem dos blocos consecutivos de células que devem ser preenchidos. O objetivo foi aplicar diferentes estratégias de busca e otimização para resolver o problema de forma automatizada.

🌱 AgroLinq — Conectando a Agricultura Local e Sustentável

Next.js React TypeScript Tailwind CSS MongoDB Engenharia de Software

Desenvolvido na disciplina de Engenharia de Software II, o AgroLinq é uma plataforma web projetada para conectar diretamente pequenos produtores rurais a restaurantes e consumidores finais. A solução visa aproximar a cadeia de abastecimento local, alinhando-se aos Objetivos de Desenvolvimento Sustentável (ODS 2, 12 e 13) ao promover o consumo responsável e fortalecer a agricultura sustentável com cadastros centralizados e autenticação segura.
